

                   어쩐지 좋은일이 생길것 같은 저녁 



  게임 소개

저희 T.G Entertainment의 '어쩐지 좋은일이 생길것 같은 저녁'(이후 어쩐지~저녁)을 
구입해 주신데 대해 감사드립니다.

어쩐지~저녁은 주간 소년 챔프에 인기리에 연재되었으며 100만부가 넘는 단행본 
판매 부수를 기록했던 작가 이명진 선생님의 만화`어쩐지 좋은일이 생길것 같은 
저녁'을 격투 액션 게임으로 만든것이다.

게임의 쟝르는 종,횡 스크롤의 스트리트형 격투 액션 게임으로서 주인공과 친구
들을 괴롭히는 적들을 쓰러뜨리면서 각 에피소드를 클리어하며 게임을 진행시켜 
나가게 된다. '어쩐지~~저녁'은 박진감있는 액션성에 중점을 두어 총 300프레임
이 넘는 동작들과 현실감 있게 구성된 60가지가 넘는 기술들이 건의 기술에 사용
되었으며 게임성을 살리기 위해 EXP와 근성치 시스템, 액션의 연계와 캔슬등 여
러 섬세한 배틀시스템들로 만들어져 있다.
또한 적들을 쓰러뜨릴때마다 얻는 경험치에 의해 주인공 건은 기술, 스피드, 파
워, 체력 등의 다양한 파워업을 하며 성장을 해나갈수 있는 기존의 액션 게임에
서는 볼수 없었던 새로운 방식의 게임 시스템도 준비되어 있다.

- 스토리 소개 -
잦은 싸움과 말썽만 일삼던 주인공 남궁 건은 다시는 싸우지 않겠다는 어머니와
의 약속과 함께 북예고로 전학을 오게 된다. 건은 새로운 생활을 시작하려고 하
지만 건을 따라 다니는 '지존 고교의 캡틴'이라는 호칭은 자꾸 건에게 예전의 모
습으로 돌아가기를 강요하게 된다. 하지만 친구인 미나가 소매치기 일당들에게 
납치 되는 사건, 또 예전 자신이 다니던 지존고교의 새로운 캡틴 종석이가 벌이
는 사건등을 겪게 되면서 건은 과거의 불량배에서 벗어나 친구들의 우정과 사랑
을 겪으며 바르고 건실한 남자로 성장해 나가게 된다. 

게임에서의 스토리는 일괄된 진행이 아닌 에피소드 형식으로 구성되어 있다.
각 에피소드는 코믹스에서의 스토리들을 바탕으로 한 사건들과 불량배였던 건의 
과거편이 등장하는 게임만의 오리지날 에피소드들로 구성되어 있다.

  게임의 시작

  윈도즈 95에서의 실행

1 : 시작 메뉴의 프로그램 폴더에서 NIGHT의 폴더를 선택후 NIGHT 아이콘을 더블 
    클릭하면 게임이 실행됩니다.
2 : 윈도즈95의 도스창을 전체 화면 모드로 한후에 어쩐지~저녁을 인스톨한 디렉
    토리로 이동후 NIGHT.BAT 파일을 실행 시킨다. * 한글 도스창이 아닌 영문 도
    스창일 경우 NIGHT.EXE를 실행하여 주십시오.

* 게임 플레이중 주인공 건이 자꾸 점프를 하는 상황이 발생하면 NUMLOCK키를 OFF
  상태로 한후 게임을 실행하여 주십시오.

* 윈도즈 95에서는 시스템에 따라 1번 방법으로 실행시 어쩐지~저녁의 게임을 
  끝낸후에 빠져나올때 다운이 되어버리는 경우가 있습니다.
  이럴때에는 시스템을 재부팅한후 2번의 방법으로 게임을 실행하거나 게임 실행 
  아이콘인 NIGHT아이콘의 등록정보에서 화면 사용을 창모드에서 전체화면으로 
  전환하여 주십시오.
  * 아이콘 등록 정보의 창모드에서 전체화면으로의 전환 방법.
          시작 메뉴에서 마우스의 오른쪽 버튼을 클릭하여 열기를 선택한다.
          시작 메뉴의 폴더가 열리면 프로그램 폴더를 선택하여 더블 클릭한다.
          프로그램 폴더가 열리면 NIGHT의 폴더를 선택하여 더블 클릭한다.
          NIGHT폴더안에 있는 아이콘에 마우스 커서를 위치시킨후 오른쪽 버튼을 
          클릭한다.
          메뉴중 '등록 정보'를 선택한다.
          등록 정보가 나타나면 메뉴중'화면'을 선택한후에 '화면 사용' 항목에서 
          '전체 화면'을 클릭하여 창모드에서 전체 화면 모드로 전환한다.
          확인을 눌러 종료한다.


  DOS에서의 실행

1 : 어쩐지~저녁을 설치한 디렉토리로 이동후 도스일 경우에는 'NIGHT' 라고 입력한다.
    * 영문 도스일 경우에는 'NIGHT.EXE' 라고 입력하여 주십시오.(그냥 NIGHT로 입력
      해도 게임 실행에 지장은 없습니다)

* 반드시 게임 실행전에 NUMLOCK키를 OFF 상태로 놓아주십시오.

        CTRL,   ALT,     SPACE       /      펀치,  킥,   앉기

위의 방식과 

          SHIFT,   Z,   X              /       점프,  펀치, 킥
                           SPACE      /                      앉기

        < 타이틀, 포즈&옵션 화면, 레벨업모드 화면에서의 키 조작 >

* F1키 - 레벨업모드 화면에서의 헬프 메세지 키


  포즈 & 옵션 화면에 대하여

* 게임의 일시 정지와 옵션 메뉴를 선택할수 있습니다.

  옵션 메뉴 - LEVEL UP MODE
              COMMAND LIST
              BGM MODE
              SOUND MODE
              EXIT TO DOS

        < 옵션 메뉴 설명 >
  LEVEL UP MODE - 레벨업 모드 화면으로 전환합니다.
  COMMAND LIST - 건이 사용할수 있는 기술들의 설명과 커맨드를 레벨별로 볼수 있습
니다.
  BGM MODE - 배경 음악의 출력 여부를 결정합니다.
  SOUND MODE - 효과음의 출력 여부를 결정합니다.
  EXIT TO DOS - 게임을 중단하고 도스로 빠져나갑니다.


  레벨 업 모드 화면에 대하여 

* 현재까지  건이 적에게서  얻은 경험치를  사용하여 TECHNICAL  LEVEL, H.P   MAX, 
POWER, 
SPEED의 레벨을 올리거나 H.P RECOVER, CONTINUE+ 의 메뉴를 결정할수 있습니다.
레벨업 모드는 게임중 포즈&옵션 화면에서 들어갈수 있으며 에피소드 스테이지의 구역 
전환시나 에피소드 클리어시에 자동으로 들어가집니다.

        < 메뉴 설명 >

  TECHNICAL LEVEL(기술 레벨 ) - 건이 사용할수 있는 기술 레벨을 올립니다.
레벨이 올라갈수록 건이 사용할수 있는 기술들의 수가 많아집니다. 덧붙여 테크니컬 레벨은 
건이 파워업 하는데 있어 가장 중요한 부분입니다. 최고치는 레벨 4입니다.
게임 시작후에는 우선 최대한 빨리 기술레벨을 1로 올려놓는것이 게임 진행에 편리합니다.

  H.P MAX(체력 최대치) - 레벨을 올릴수록 건이 가지고 있는 체력의 최대치가 늘어납니
다.
게임 시작시 건의 기본 체력은 100이며 최대치는 레벨별로 100씩 올라갑니다. 
체력의 최대치가 올라가면 손상되었던 H.P는 자동으로 회복되어집니다.
최고치는 레벨4 입니다.

  POWER(파워=공격력) - 건이 가지고 있는 필살기들의 공격력을 올리며 몇몇 기술들은 
공격력이 올라가는 동시에 기술의 특성이 강력한 성질로 바뀌어집니다. 특성이 강화된 기술
들은 사용했을때 적을 일반적인 다운을 시키지 않고 공중으로 높이 띄우거나 화면끝에서 
퉁겨나오게 합니다. 이때에는 공중 콤보로 적에게 커다란 대미지를 줄수 있습니다.
그 외에 파워 레벨 2단계에서는 특정 기술들에게 무적 시간도 더해집니다.
POWER 1과 2의 2단계로 구성되어 있습니다.

  SPEED(스피드) - 건의 이동 속도를 높입니다. 

  H.P RECOVER(체력 회복) - 건의 체력을 최대치까지 회복시킵니다.

  CONTINUE+ (컨티뉴 증가) - 게임의 컨티뉴 회수를 1회 늘립니다.

* H.P RECOVER와 CONTINUE+ 는 에피소드 스테이지의  구역전환시나 에피소드 클리어
시에 
자동으로 들어가지는 레벨업모드 화면에서만 사용할 수 있습니다.


  게임 시스템에 대하여

* EXP 시스템 :  적들을 쓰러뜨리면 그 적이 가지는 고유의 경험치를 얻게 됩니다.
강한 적일수록 많은 경험치를 가지고 있습니다. 

* 근성치 시스템 : 게임상에 등장하는 몇몇 적들에게는 근성치가 설정되어 있습니다.
이 근성치는 H.P가 0가 된 후에도 건의 공격에 버틸수 있는 적의 내구력을 의미합니다. 
H.P가 0이 되면 적은 적색으로 깜박이기 시작합니다. 이 상태를 그로기 상태라고 칭합니다.
그로기 상태에서 적이 건에게 넘어지는 기술을 맞게되면 적은 바로 쓰러지지만 넘어지지 
않는 일반 기술을 맞게 되면 근성치만큼 적이 버티게 됩니다. 이때 근성치도 0가 되면 적은 
바로 쓰러집니다.  그로기 상태의 적에게 주는 대미지는 모두 경험치로 추가되어 집니다. 
때문에 적이 가진 근성치를 이용하여 건은 일반적으로 적을 쓰러뜨렸을 때보다 훨씬 더 많
은 
경험치를 취할수 있습니다. 근성치는 H.P와는 달리 게이지로 표시되지 않습니다.

* 액션 캔슬 시스템 : 점프, 앉기, 잡기의(앉기와 잡기는 기술레벨 1이상에서 사용가능) 
세 가지 기술은 건의 액션을 캔슬(취소)가능합니다. 때문에 건이 적에게 공격 당하거나 또는 
공격하는 도중 언제라도 사용할 수 있습니다. * 단 건의 기술중에는 캔슬할수 없는 것도 있
습니다.

* 회피 시스템 : 앉기 기술을 사용하여 앉아 있는 동안에는 적의  상방향 공격을 맞지 않습
니다.
 또한 점프 상승중에는 적의 공격을 피하기 쉽습니다. 앉기와  점프는 건이 적에게 공격 당
하는 
도중에도 사용 가능하므로 위기시에는 점프나 앉아서 적의 공격을 회피하여 주십시오.

* 공중 콤보 시스템 : 적이 건에게 공격당하여 공중에 떠 있을때도 건은 적을 공격 할수 있
습니다. 
또한 공중에 떠있는 적에게는 평상시의 공격보다 두배의 대미지를 줄수 있으므로 공중 콤보
를 
사용하여 적에게 강력한 공격을 할수 있습니다.

* 다운 공격 시스템 :  적이 다운되어 바닥에 누워 있을때도  '다운 어택'이나 하단 방향의 
공격을 
하는 기술들로(예:로킥) 적을 공격할수 있습니다. 이때도 역시 공중  콤보와 같이 공격 대미
지는 
두배가 됩니다.


  커맨드 리스트

* 건이 사용하는 기술들의 커맨드와 내용입니다.  아래의 내용들은 게임중 포즈&옵션 화면
에서 
'COMMAND LIST' 메뉴를 선택하면 볼수 있습니다.

* 기술 입력의 방향은 건이 오른쪽을 바라 보고 서 있을때를 기준으로 하였습니다.

* 각 커맨드에서의 키 표시는 다음과 같습니다.
  P - 펀치(CTRL 또는 Z키)  ,  K - 킥(ALT 또는 X키)  ,  J - 점프(SHIFT키)
 SPACE - 앉기(SPACE 키)

        < 기술 레벨 0 >

* 게임 시작시의 건이 가지는 레벨이며 이때는 기본적인 펀치 4연타와 킥 4연타,
  점프 공격 밖에 할수 없습니다. 우선은 최대한 빨리 건의 테크니컬 레벨을 1단계
  로 올려 주십시오.


        < 기술 레벨 1 >

* 대쉬 : →, →    / 적과 부딪히면 대쉬자체에 공격력이 발생합니다.
* 러쉬 : →, →, → / 전 방향으로 달려갑니다.
* 러쉬 태클 : 러쉬중에 P 또는 K / 적을 쓰러뜨리는 슬라이딩 킥을 냅니다.
* 콤보 백어택 & 스트레이트 : P, P, P, K, P
  기본 펀치 4연타의 중간에 후방의 적을 쓰러뜨리는 발차기를 냅니다.
* 잡기 : P+K  / 전방에 있는 적을 붙잡습니다. 적을 붙잡은 상태에서 던지기나 
  타격기의 다른 기술로 연결시키는 일이 가능합니다. 
* 건즈 넥드롭  : 적을 잡은 상태에서 →+P
* 건즈 쓰로우  : 적을 잡은 상태에서 ←+P  
                 두가지 모두 건의 가장 기본적인 던지기입니다.
* 바디 크래쉬  : 적을 잡은 상태에서 P
*   니 어택    : 적을 잡은 상태에서 K
* 니&사이드킥  : 적을 잡은 상태에서 K, K, K, K, K
                 세가지 모두 적을 잡았을때만 넣을수 있는 타격기입니다.
* 대쉬 점프 : 러쉬 또는 대쉬중에 J  
              보통 점프보다 이동 거리가 넓습니다.
* 스위핑 킥 : 쓰러져 있는 중에 K   
             건이 일어나면서 주위의 적들을 발로 공격합니다. 적들에게 둘러 쌓여 
             있을때는 잊지말고 사용하여 주십시오.
* 숄더 어택 : 앉은 상태에서 P   
              적의 공격을 앉아서 피한후 바로 공격을 해야 할 경우 유효하며 공격이
              들어갔을 경우 적의 경직이 있기 때문에 뒤에 후속타를 넣기가 쉽습니다.
* 라이트닝 니 : 적을 잡은 상태에서 →+K   
                니 어택과 다른 점은 빠르고 단발성이며 공격후에 적을 놓기 때문에 다른 
                타격기로 연결시키거나 다시 잡기를 할수 있습니다.
* 스트레이트 펀치 : → + P
                    적을 다운 시키는 단발 기술입니다.
* 낙법 : 적의 공격을 받고 다운되는중에 J  
         건이 적에게 공격당하여 쓰러질때 공중에서 땅으로 떨어지는 도중에 낙법을  합니
다. 
         입력을 빨리하면 건이 공중에서 회전한후 땅에 쓰러지지 않고 착지하며 입력이 
         늦어도 땅에 쓰러져있는 경직 시간을 줄여 바로 일어나게 됩니다.
* 앉기 : 스페이스 키 또는 Z키  
         건이 앉는 자세를 취하며 상대의 상방향의 공격을 피할수 있게 됩니다. 
         이 행동의 중요한 점은 건이 적에게 공격 당하고 있는 모션중에도 바로 앉을수 
         있으므로 후속타를 피할수 있다는 것입니다. 또한 건이 다른 공격을 하고 있는 
         중에도 그 공격의 행동을 취소하고 바로 앉을수  있습니다. 이외에 점프와 잡기로
도 
         건의 맞는 동작이나 공격의 행동을 취소할수 있습니다. 특히 제자리에서 하는 
         점프는 상승하는 순간 건이 무적이 되므로 적의 공격을 쉽게 피할수 있습니다.  
         앉기와 점프, 잡기를 잘 사용하며 게임을 진행시켜 주십시오. 


        < 기술 레벨 2 >

* 콤보 피스톤 스트레이트 펀치 : P, P, P, ←, →, P  
  건의 가장 기본적이면서도 강력한 연속기입니다. 마지막의 피스톤 펀치는 적과의 
  거리가 가까울수록 다단 히트 합니다.         
* 콤보 스핀킥 : K, K, K, ←, K  
                킥 3연타후 돌려차기를 냅니다. 이 공격은 사정 거리와 범위가 가장 큰 공
격중
                하나입니다.
* 대쉬 엘보 : →, →, P
              3연속 히트의 기술로 적과의 거리에 따라 히트 수가 달라집니다. 

* 대쉬 하이 엘보 : →, →, P, P
                   대쉬 엘보에 이어 적을 다운 시키는 하이 엘보를 냅니다.
                   타이밍에 따라 대쉬 엘보의 3연타를 모두 히트시킨후에도 연결시킬수 
                   있습니다.
* 대쉬 슬라이딩 킥 : →, →, K    3히트의 슬라이딩 공격입니다. 공격의 타점이 전방에 있
기 
                                때문에 적과 너무 가까이 있으면 맞지 않는다는 점에  주
의 
                                하여 주십시오.
* 대쉬 숄더 어택 : 앉은 상태에서 K
                  P로하는 숄더어택과 다른점은 사정거리가 길고 공격력이 강하며 적을 
                  다운시킵니다.
* 다운 어택 : 점프중 최고점에 이르기전에 P+K
              땅에 쓰러져 있는 적을 공격하는 강력한 다운 공격입니다. 
              적을 다운 시켰을때는 잊지말고 사용하여 주십시오.
* 푸싱 : 적에게 접근해서 →방향 진행  
         가까이에 있는 적들을 앞뒤로 밀쳐냅니다. 밀쳐진 적은 잠시 경직을 
         갖기 때문에 쉽게 다른 타격기로 연결시킬수 있으며 적에게 둘러 쌓여 있을
         때도 효과적입니다. 건의 중요한 기술중 하나입니다.
* 백 어택 : J+K 
           후방에 있는 적을 향한 단발 발차기입니다.
* 콤보 팔로윙 엘보 : 콤보 피스톤 스트레이트 펀치 후에 P
                    콤보 피스톤 스트레이트 펀치의 마지막에서 3히트의 엘보 공격이 연결
됩니다.
                     이 공격의 특징은 적을 쓰러뜨리지 않고 계속 공격할수 있는  것입니
다.
* 건즈 섬머 솔트 : ←, →, K    
                  지상에 있는 적보다는 공중에 떠 있는 적에게 커다란 대미지를 줍니다.
                  공중에 뜬 적의 높이와 위치에 따라 2히트, 때에 따라서는 4히트의 섬머 
                  블로우가 됩니다.


        < 기술 레벨 3 >

* 백 대쉬 : J+P  건이 후방 대쉬 합니다. 백대쉬중은 무적이므로 적의 기술을 피하거나 거
리를 
                  넓힐때에 사용하여 주십시오.
* 콤보 엘보 어퍼 : P, P, P, →, ↑, P
                   이 기술은 공격력이 크며 적을 높히 뛰울수 있기 때문에 후속타의 공중 
타격
                   으로 적에게 큰 대미지를 줄수 있습니다. 마지막의 어퍼컷은 적과의 거
리가 가
                   까울수록 다단 히트 합니다.


* 건즈 킥 블로우 : K, K, K, →, →, K
                   이 공격은 피스톤 스트레이트 펀치와  마찬가지로 적을 강력하게 다운 
시켜 벽 
                   등의 장애물로 부터 튕겨나오게 하므로 후속타가  가능합니다. 적이 가
까울수록 
                   마지막 앞차기가 다단 히트하며 건의  가장 강력한 연속기중 하나입니
다.
* 토네이도 엘보 어택 : →, →, P, ↓, P, →, P
  토네이도 엘보 연타후에 숄더 어택을 냅니다. 마지막까지 히트하면 적에게 강력한 대미지
를 줍니다.
* 피스톤 스트레이트 펀치 : ←, →, P를 누르고 있다가 뗀다.
                          커맨드의 마지막에서 P를  누르고 있으면 피스톤  레디 상태가 
되며 
                          P를 떼는 순간 피스톤 스트레이트가 나갑니다.  피스톤  레디일
때는 
                          무적상태가 됩니다.
* 건즈 대쉬 니 어택 : →, →, K, J
                  리치가 긴 슬라이딩 킥후에 강력한 니 어택이 이어집니다.
* 건즈 플라잉 니 : 적을 잡은후 ←, ↑, K
                  잡고 있는 적에게 강력한 무릎 공격을 냅니다. 높은 대미지를 주면서 적
을 
                  뛰우기 때문에 후속타를 넣을수 있습니다.

* 건즈 더블킥 : 제자리 점프후 J+K
                점프후에 2단 킥을 냅니다. 지상에 있는 적을  맞추기는 힘들며 엘보 어퍼

                적을 뛰운후에 공중 후속타로 사용해 주십시오.

* 건즈 토네이도 니 : ←, →, J+K 빠르고 강력한 다단히트의 단발성 공격입니다.
* 건즈 콤보 토네이도 킥 1 : K, K, K, ←, →, K, ↑, K
                           킥 연타후 마지막에 강력한 토네이도 킥을 냅니다.
* 건즈 콤보 토네이도 킥 2 : ←, →, J+P, ↑, K
                           엘보 연타후 마지막에 강력한 토네이도 킥을 냅니다.

* 스톰 : 적을 잡은 상태에서 →, ←, → ,→, P / 건의 최강 공격입니다.

  게임중 발생하는 문제점 해결

  윈도즈95에서 게임을 플레이한후 종료하면 다운이 된다. - 시스템을 재부팅한후 
   '윈도즈 95에서의 실행 항목에 있는 2번 방법으로 게임을 실행하거나 게임 실행 
   아이콘인 NIGHT아이콘의 등록정보에서 화면 사용을 창모드에서 전체화면으로 
   전환하여 주십시오.
  * 아이콘 등록 정보의 창모드에서 전체화면으로의 전환 방법.
          시작 메뉴에서 마우스의 오른쪽 버튼을 클릭하여 열기를 선택한다.
          시작 메뉴의 폴더가 열리면 프로그램 폴더를 선택하여 더블 클릭한다.
          프로그램 폴더가 열리면 NIGHT의 폴더를 선택하여 더블 클릭한다.
          NIGHT폴더안에 있는 아이콘에 마우스 커서를 위치시킨후 오른쪽 버튼을 클릭한
다.
          메뉴중 '등록 정보'를 선택한다.
          등록 정보가 나타나면 메뉴중'화면'을 선택한후에 '화면 사용' 항목에서 '전체 화
면'을 
           클릭하여 창모드에서 전체 화면 모드로 전환한다.
          확인을 눌러 종료한다.

  건이 점프키를 누르지 않았는데도 건이 자꾸 점프하는 경우가 발생 - 게임 실행전에 
NUMLOCK키를 OFF상태(램프가 꺼진 상태)로 하고서 게임을 실행하여 주십시오.

  윈도즈 95에서 효과음이 나오지 않는다 - 사운드  카드의 셋팅중 DMA를 1번으로 HIGH 
DMA를 
5번으로 바꾸어 주십시오. *한글윈도즈 95의 장치 관리자를 통해 볼 경우에는 DMA는
'직접 메모리 억세스'라고 나오며 두번째 '직접 메모리 억세스'가 HIGH DMA입니다.

  게임이 중간 중간 끊기듯 멈추면서 진행되거나 다운이 된다 - 옥소리 사운드카드의 몇몇 
버젼에서 이러한 문제가 발생하는 경우가 있습니다. 컴퓨터를 DOS모드로  부팅하여 사용해 
주십시오.
만약 도스에서도 이 같은 현상이 일어나면  옵션 모드에서 효과음을 OFF상태로 한후에 게
임을 
진행하여 주십시오.
