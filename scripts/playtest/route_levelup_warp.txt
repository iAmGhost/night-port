# lookup whose name contains NAME, then rebases the rest of the timeline by the slippage. The leading
# number is therefore both the expected slot and a generous timeout, gaps after an anchor are read relative

# counter to reach 0, which happens on the second frame of a hold).
# Level-up screen through the host debug warp (NIGHT_SHOWSCREEN=levelup, NIGHT_SHOWSCREEN_AT=<frame>): the
# game reaches fn_038f3d(1) only on stage completion, right after g_dat_63370 += 1 at 0x0003b54c (guarded by
# pl[0x30] != 1), which scripted play cannot reach in a run's lifetime. The warp calls the game's own
# routine, so the asset loads (levelup.spr / number1.spr / number2.spr, levelup.pcx or levelup2.pcx), the
# compositing and the key handling under test are the shipped ones -- only the moment of entering is
# host-chosen (the --warp-stage convention, docs/52). The warp must fire only once a stage is live: called
# with no stage loaded it faults exactly like the DAT_00063c7c null-player read of docs/55.
