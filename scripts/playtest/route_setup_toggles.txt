# Setup-menu (fn_039c03 / pause.spr) toggles, measured through the host pump counters.
# No key is needed to reach the menu: after the title card the port holds a static screen that is
# byte-identical (L1 0.00) to the frame the earlier route called "menu", and it stays identical for over
# 20 s. Down walks the entry index m 0 -> 4 -> 3 -> 2; Right/Left toggle f[m], meaningful at m==4 (the
# DAT_00053ddc stream), m==3 (MUSIC, DAT_00053338 -> snden=) and m==2 (sound EFFECTS, DAT_00051a10 ->
# sfx=, plus a CD track select or stop -> tracks=/cdstops=). Each press arms auto-repeat for 0x13 frames,
# so presses are separated by a second.

120000 wait res title1.pcx

129150 key down up
