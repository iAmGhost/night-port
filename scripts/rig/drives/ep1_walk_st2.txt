# Stage-walk drive (docs/313): reach EPISODE 1, STAGE 2 the way a player does, then stand at the bottom.
#
# Why this exists: the previous "stage 2" bases were wrong twice over.  `--warp-episode 2` loads episode 2
# (a different map, docs/312 0a) and `--warp-stage 2` installs a node without re-loading that stage's
# background (the playtester saw stage 1's subway art still painted in ep1-stg2).  Neither can carry a
# camera or sprite claim.  This drive uses no warp flag at all: it walks episode 1's own room chain.
#
# A stage advance is one call of fn_03d244 (it swaps DAT_63354 to node+0x34c, or to the terminator
# g_dat_63350 at the last node, 0x3d286-0x3d2a2) and the harness counts those calls (f_rig_chain_advances,
# f.c rig scaffolding).  Each advance opens the level-up screen (fn_038f3d(1) at 0x3d2ac), which leaves only
# on Esc/LShift/RShift (0x3920a-31) -- so the drive waits for it (`wait state menu-open`), hands it Esc, and
# waits again (`wait state menu-closed`) instead of guessing when it finished.  The fixed-time key plans that
# spent most of their budget inside fn_038f3d are what the playtester meant by "stuck on the upgrade menu".
#
# The requests are arm 2 (DAT_6336c = 2, the exit-rect arm fn_03a829 handles at 0x3ac2a-0x3ac7b and
# fn_00012dcc writes at 0x12e8f-0x12ef0).  Arm 3 (the latched guardian dying) is the only arm that ends an
# episode, and it is not what a stage-1-to-stage-2 transition uses (docs/312 4).  Right is held so the player
# is walking toward the exit rect when the request lands, as in play.
#
# Measurement window for item D: after the menu closes, Down is held for ~36 s and then Right is held --
# the playtester's own order ("only after the bottom did I reach enemies").  DAT_639e0 (the vertical scroll
# row), DAT_639dc (horizontal), DAT_639e4 (scroll-active flag) and the [vgate] gate census cover that window.
#
# Menu macro (docs/313): the screen fn_038f3d(1) opens at 0x3d2ac begins in fn_00035dfc's card wait, which
# accepts only Enter/CTRL/ALT/Space (docs/97); Esc alone cannot leave it, and the run then burns its frame
# budget inside the screen -- measured 10858 of 12000 frames menu-owned on the first attempt.  The macro here
# advances the cards with Enter pairs and only then sends Esc (0x3920a-31 is the exit test).
